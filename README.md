## Назначение

Библиотека реализует функциональность для работы с транспортными протоколами, основанными на WebSocket. Она предоставляет абстракцию для создания, обработки и управления командами и событиями в рамках взаимодействия между клиентами и серверами. Библиотека является частью общего набора инструментов для разработки распределённых приложений, которые требуют связи между компонентами на разных серверах или устройствах. Она включает в себя необходимые механизмы для обработки команд и событий, управления клиентами и обработки ошибок, что делает её надежным решением для разработки распределенных приложений в реальном времени.
